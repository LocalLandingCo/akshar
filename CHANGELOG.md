# Changelog

All notable changes to this project are documented here. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); entries
are generated from [Conventional Commits](https://www.conventionalcommits.org/)
via `npm run changelog`.

This project hasn't tagged a release yet — there's nothing to generate a
diff against. The first `npm run changelog` run, at the first tagged
version, replaces this file's content with the real generated log.

## Unreleased

Initial MVP under active development. See the commit history for what's
landed so far; commit messages before the `feat:`/`fix:`/… convention was
adopted (documented in `CONTRIBUTING.md`) won't appear correctly in a
generated changelog — this file starts clean from the first tagged
release rather than attempting to retrofit that history.
